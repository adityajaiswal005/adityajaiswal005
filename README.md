## 🧩 01 — AlgoVisualiser

### **Learn Algorithms. See Them. Understand Them.**

An interactive algorithm visualization platform designed to make complex **DSA concepts easier to understand through visual execution**.

### ✨ Highlights

* 📊 Visualizes popular sorting and searching algorithms
* 🎬 Step-by-step algorithm execution
* ⚡ Interactive controls for learning
* 🧠 Helps understand algorithm behavior instead of memorizing code
* 📈 Designed for students and DSA learners

### 🛠️ Built With

`React` `JavaScript` `HTML` `CSS` `Algorithms` `Data Structures`

🔗 **Repository:** `https://github.com/adityajaiswal005/AlgoVisualizer`

* 🔎 Search and filtering
